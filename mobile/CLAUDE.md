# CLAUDE.md — mobile

React Native **CLI** app (not Expo), TypeScript strict. Run commands from inside `mobile/`.

## Commands

```bash
npm install
npm start                 # Metro
npm run android           # needs JDK 17, Android SDK (ANDROID_HOME), emulator or device
npm run lint && npx tsc --noEmit && npm test
```

iOS builds need macOS + Xcode (`cd ios && bundle install && bundle exec pod install`, then `npm run ios`).

## Architecture rules

- `src/theme/` is the only place for colors, typography, spacing, radius and shadows. No hex values elsewhere.
- One reusable component per file in `src/components/`; feature-only pieces live in `src/features/<feature>/components/`.
- Screens call hooks; hooks call services; services call `src/services/api/apiClient.ts`. No `fetch` or API calls in components.
- Pure calculations and formatting go in `src/utils/` with unit tests in `__tests__/`.
- Auth tokens are stored with `react-native-keychain` (`src/services/storage/secureStorage.ts`), never in AsyncStorage.
- Environment values (API base URL, policy URLs) live in `.env` (copy `.env.example`; git-ignored), read through `react-native-dotenv` only in `src/config/env.ts`. Values are baked into the bundle, so never put secrets there; restart Metro with `npm start -- --reset-cache` after editing.
- Do not introduce Expo or Expo-only packages. Use `android/` and `ios/` as generated by the CLI; change native files only when required.

## API

Uses the backend in `../backend`; endpoint contracts are in `../backend/docs/api`. Every service calls `apiClient` except chat, which still returns the fixtures in `src/services/mockData.ts` because the backend has no messaging endpoints yet. Replace the chat service body and delete the mock file when they exist. Map API shapes to app types in `src/services/mappers/`, keep wire types in `src/types/api.ts`.

## Releases

See `STORE_READINESS.md` for the Google Play / App Store checklist. Release builds are signed from `android/keystore.properties` (git-ignored); without it the release build is left unsigned.
